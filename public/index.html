How It Works

STRICT SPLIT: Divides your original code into completely separate groups. If a game is in Group 1, it will never appear in Group 2. Perfect for spreading risk across completely different matches.

SHUFFLE: Randomly selects games for each group. Games from Group 1 can appear in Group 2, giving you a fresh, randomized combination every time while keeping your favorite picks in the mix.
